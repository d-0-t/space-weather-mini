# Webcams page — curated live sky camera gallery (client-side)

Status: ready-for-agent

## Problem Statement

Aurora chasers get forecasts, indices and alerts from the app, but no *sky*. The competitors all show webcams (SpaceWeatherLive's directory, My Aurora Forecast's cams, Shetland/UK cams), and for the field user a live sky camera is the ground-truth check before stepping outside. The app is client-side-only (ADR-0001) and will never run its own cameras; it already displays external imagery (OVATION JPGs, Kiruna magnetogram) so embedding operator-served webcam stills is a natural extension — provided the app stays honest about freshness, respects operators' licenses, and never wastes the chaser's data budget without consent.

## Solution

A new top-level route `/webcams` (nav entry **Webcams**, between Dashboard and Details) presents a **curated live sky camera gallery** in three viewing modes (added 2026-08-31), switched by tabs that share the heading row:

`[h1 "Webcams" + tabs (Relevant now | My selection | All cameras)] → per-tab description → toolbar (Refresh / Pin webcam to dashboard / auto-refresh; Filter + Hidden sources join in "My selection") → curated: flat card grid | selection & all: Jump to → region sections → Webcam links (with "Looking for more?" note)`

- **Viewing modes** (added 2026-08-31): **Relevant now** is the default – the handpicked curated list (see below), rendered as one flat card grid with no region groupings and no collapsible panels, ignoring the user's filter and hidden settings entirely. **My selection** is the user's gallery – the region filter and hidden sources apply here, and the Filter/Hidden sources buttons plus the per-card Hide buttons render only in this view. **All cameras** shows every entry with nothing filtered or hidden. Switching tabs never touches the persisted settings; the selected tab itself persists in `localStorage["sw:webcams:view:v1"]` (default "curated"). Tabs are a WCAG automatic-activation tablist (`role=tablist/tab/tabpanel`, arrow keys + Home/End, roving tabindex) styled as underline tabs, not buttons.
- **Curated list (Relevant now)** (added 2026-08-31, updated 2026-08-31): `CURATED_WEBCAM_IDS` in `src/data/webcams.ts` – a fixed, ordered handpicked set chosen for reliability, image quality and maintenance: Kiruna (IRF), Tromsø/Abisko, Porjus (Jokkmokk) #1–5, Hankasalmi, Yellowknife (AuroraMAX), Gillam/Pinawa/Rabbit Lake, Kapuskasing, Isle Royale - North Shore, Hope NJ, Animas NM, Kaliningrad – plus the Lights over Lapland Twitch embed (all with short display names; original long names preserved as comments in `webcams.ts`). Each curated cam adapts to its **local darkness**: `isSunBelowHorizon(latitude, longitude, now)` in `src/data/sun.ts` (NOAA solar-elevation approximation; actual sunrise/sunset for the day, twilight counts as dark) hides a station only while the sun is actually up at its location, including midnight-sun seasons; the gate re-evaluates every minute. Seasonal cams are removed only in total daylight. The per-tab description explains the selection.
- **Pinning across views** (added 2026-08-31): pins are set from any view, and the pin strip lists **pinned cams not visible in the current view** (hidden sources, filtered-out cams, live cam absent from the curated list…) with their own "Unpin" toggles, so off-screen pins can never lock every visible checkbox.
- **One gallery item per source** (no per-region cards). Image cards first; link rows after.
- **Image card**: title `{Station} · {lat}°N/S`, region tag, operator's current still (plain `<img>`, cache-busted on refresh), **"Loaded {HH:MM} · Refreshes every {N} min"** with any seasonal note appended inline (honest — CORS forbids a true timestamp), operator attribution + license note, "Visit site" link, FullSizeModal on click, Hide button (`btn--icon` VisibilityOff small, intentionally asymmetrical padding/margin `-1.35rem -1.75rem` for larger touch target away from the cam image). In pinning mode the title row's Hide is replaced by a **Pin selector**: the entire card is the visual checkbox (unselected = faint dashed border `1px dashed var(--color-border-muted-transparent)`, selected = thick solid `3px solid var(--color-accent-strong)`), but the click target is a single `btn--icon` pin button (`PushPin` 30deg, large `1.5rem` gold `var(--color-gold)` default, `var(--color-accent-strong)` on hover, symmetric padding) with `title` + `span.sr-only` naming the native hidden `input type=checkbox` (WCAG checkbox semantics + keyboard).
- **Link row**: station, region, operator, kind note ("YouTube stream", "Twitch stream", "site player", "Webcam"), external link in new tab.
- **Region filter**: a **Filter** button (labelled "Filter (N)" with the applied count) opens a popup `<dialog>` checklist - one **native checkbox** per region present in the config, fixed display order, absent regions don't render (every region in the registry, incl. the `rest` bucket labelled "Other regions", so no entry is ever unfilterable). Checked means **keep only those regions**; **zero checked shows everything** (no artificial "All" entry). **Select all** (check every draft box) and **Deselect all** (uncheck every draft box) toggle the draft without committing (renamed and reversed from the original Show/Hide all, user decision 2026-08-29); **Apply** commits and persists, Cancel/Escape discard, focus returns to the Filter button. An applied filter narrows image cards *and* link rows; the "No webcams match your filters" empty state renders when the filter + hidden set together leave nothing. The Filter and Hidden sources buttons appear only in the **My selection** view.
- **Hide** applies to image, live and Twitch cards (link rows lost their Hide buttons, ticket 07; the Hide buttons render only in **My selection**): the item leaves the gallery (its image is never fetched), a **"Hidden sources (N)"** button in the toolbar — the count in the label, kept live — opens a dialog listing hidden entries with one-tap restore. Persisted in `localStorage["sw:webcams:hidden:v1"]` (array of ids, versioned).
- **Auto-refresh** is opt-in (`localStorage["sw:webcams:autorefresh:v1"]`, default off): a **native checkbox** setting labelled with the derived cadence range ("Auto-refresh images (1–15 min)" – the refreshable registry min–max, single value as "60s"/"N min"; the honest data-use note sits in the checkbox `title`, ticket 05). When on, image cards marked `refreshable` reload on their operator cadence (never faster than the source's own cadence – `max(cadenceMinutes, 1)` – cache-busted with `?t=`); UAF Poker Flat follows its CORS-open SSE feed for true ~5–15 s live frames. Refreshing pauses while the tab is hidden (visibilitychange), mirroring ADR-0003. The page-level **Refresh** button in the toolbar always works (user decision 2026-08-29: one Refresh button, no per-card refresh buttons). Refresh, the Pin button and auto-refresh render in every view; the toolbar sits below the tabs, above the Jump to row.
- **Lights over Lapland** is the one video-embed card: Twitch iframe (`player.twitch.tv/?channel=lightsoverlaplandlive&parent=<domain>&autoplay=false&muted=true`) — nothing streams until the user presses play — plus a "Watch live on Twitch" fallback link. It joins the curated gallery in **Relevant now** as well as the full gallery.
- **Seasonal notes** ride on the config: a cam that shuts down for daylight/midnight sun (AuroraMAX off May–Aug, most all-sky cams in summer) shows its note on the card instead of a stale frame with no explanation.
- **"Looking for more?"** sits at the end of the **Webcam links** section, after the last link row (not the page footer): one honest line pointing at the **EarthCam world map** link for self-service during big storms ("Looking for more? The EarthCam world map finds webcams from around the world", ticket 05).

## User Stories

1. As a chaser, I want a top-level **Webcams** page in the nav (route `/webcams`, own entry — webcams are not NOAA products), so that I can see live skies without digging through Details.
2. As a chaser, I want one gallery item per webcam or source — image cards first, video/unembeddable sources as link rows after — so that the page reads as a wall of cams, not a list of regions.
3. As a chaser, I want each image card to show the station name **with its latitude** (e.g. "Tromsø · 69.6°N"), the region, and the operator, so that I can judge a cam's relevance at a glance.
4. As a chaser, I want every card to carry "Loaded {HH:MM} · Refreshes every {N} min" (notes appended inline) rather than a fake age, so that I know exactly how stale the sky I'm looking at can be.
5. As a chaser, I want per-region filter chips (Nordic, Alaska, North America, Australia, …) over the gallery, so that I can isolate my hemisphere.
6. As a bandwidth-conscious chaser, I want to hide any source — image card or link row — so that it disappears from the gallery entirely (image never fetched), with a **Hidden sources** dialog to restore them, persisted across visits.
7. As a chaser with the page open on a second screen, I want an **opt-in auto-refresh** setting (a native checkbox, default off, honest data-use copy) that reloads image cards on their operator cadence and pauses when the tab is hidden, so that I can watch the sky without pressing refresh — on my terms.
8. As a chaser, I want the one truly live cam (UAF Poker Flat) to update itself via its SSE feed when auto-refresh is on, so that Alaska's sky is as fresh as the operator makes it.
9. As a visitor, I want Lights over Lapland embedded as a Twitch player that does **not** autoplay (nothing streams until I press play), with a fallback link, so that I get the famous cam without surprise bandwidth.
10. As a visitor, I want attribution and license notes on every card and link row, so that operators are credited and commercial-use restrictions are visible.
11. As a visitor, I want the "Looking for more?" note naming the coverage gaps plus the **EarthCam map** link, so that during a Kp8–9 storm I can find a cam anywhere myself.
12. As a keyboard/screen-reader user, I want alt text on every image ("{Station}, {region} — current sky view"), an `aria-label`/title on the Twitch iframe, dialog semantics + focus management on the Hidden sources dialog, **all selectable chips and settings as real native elements (checkboxes)**, and WCAG 2.1 AA throughout.
13. As a developer, I want the gallery driven by a typed config (`src/data/webcams.ts`) — one entry per source with id, name, region, latitude, operator, imageUrl, cadence, `refreshable`, license, note — so that a dead or licence-changed cam is a config edit, not a code change.
14. As a developer, I want every still URL verified hotlinkable (browser-UA + foreign-Referer probe, per `docs/research/webcam-sources-2026-08-29.md`) before it lands in the config, and the config contract tested.
15. As a chaser, I want **Select all** / **Deselect all** buttons beside the chips that swiftly check/uncheck every region at once — without affecting the sources I've individually hidden — so that I can clear the gallery or blank it in one tap, and an honest empty state when nothing matches.

## Implementation Decisions

- **Config as single source of truth** (`src/data/webcams.ts`, typed, no `any`): `WebcamImageEntry` (id, name, region, latitude to 1 decimal, **longitude to 1 decimal east-positive — curated cams only, feeds the darkness gate**, operator, imageUrl, cadenceMinutes, refreshable, license: string | null, note: string | null, alt), `WebcamTwitchEntry` (id, name, region, operator, twitchChannel, note), `WebcamLiveEntry` (id, name, region, country, latitude, operator, imageUrl, sseUrl, frameBaseUrl, license, note, alt, siteUrl – added 2026-08-29, ticket 03: the one true-live cam), `WebcamLinkEntry` (id, name, region, operator, url, kind: "youtube" | "twitch" | "player" | "http-only", note). **`CURATED_WEBCAM_IDS`** (added 2026-08-31, updated 2026-08-31) is the ordered "Relevant now" set (now Porjus #1–5, Yellowknife short name); **AuroraMAX** is now titled "Yellowknife" with alt still "AuroraMAX – Yellowknife" (shortened 2026-08-31, original preserved as comment). The registry ships with the verified 2026-08-29 set from the research doc — all still-operating image sources, plus the video/unembeddable set as links, now with short display names (originals as comments). Jokkmokk is flagged `license: null` (no license text found — embedded with visible attribution per user decision; the risk member).
- **Local darkness gate** (`src/data/sun.ts`, added 2026-08-31): the NOAA solar-elevation approximation (equation of time, solar declination, hour angle over UTC + 4 min/° longitude) yields `isSunBelowHorizon(latitude, longitude, date)`. The threshold is the horizon, not full night — twilight counts as dark (auroras can be on), and a station is skipped only in local daylight, including midnight-sun seasons. The "Relevant now" gallery re-evaluates the gate every minute.
- **Ordering**: image cards grouped by region in the fixed region order (Nordic, Alaska, North America, Australia), then the **Live cam** section (added 2026-08-29, ticket 03), then Twitch/other embeds, then link rows grouped by region (New Zealand, UK, Greenland, Russia, rest). Chips order matches; chips render only for regions present in the config.
- **Refresh mechanics**: manual refresh = the header **Refresh** button re-renders every image card's `<img>` with `?t={Date.now()}` (works regardless of the setting and the tab state). Auto-refresh (on) = per-card `setInterval` at `max(cadenceMinutes, 1)`, cleared on visibilitychange-hidden, re-armed on visible. Each card owns its `src` and "Loaded HH:MM", updated on every reload. UAF Poker Flat is its own card component (`WebcamLiveEntry`): an `EventSource` on the verified `https://allsky.gi.alaska.edu/src/checkLive.php?cam=poker-flat` (the spec URL omits `/src/`) → first frame path from the data line → `<img src = frameBaseUrl + path>`, gated by the global auto-refresh, the visible tab, and the per-card "Live updates" toggle (native checkbox, default on, visit-only); on feed failure the card swaps the still for an honest "live feed unavailable" note with the operator link and withholds the freshness claim; whenever the feed stops the card reverts to the operator's placeholder still. Twitch card never auto-refreshes (the player is live itself).
- **Native controls only**: region chips are native `<input type="checkbox">` styled as chips (multi-select; zero checked shows every region — no artificial "All" chip), the auto-refresh setting is a native checkbox (checked state is the announcement — no `aria-pressed` anywhere), the Hidden sources trigger is a native button, and the Hidden sources dialog uses the native `<dialog>` element (`showModal()` gives focus management and Esc for free; fall back to the app's existing modal pattern only if a blocker appears). **Buttons use the shared system** (ticket 05 + 2026-08-31 polish): `btn--secondary` toolbar controls (Refresh/Filter/Hidden/auto-refresh, icon + collapsible `.btn__label` span + `title` tooltip — no `aria-label` since 8cdae36), `btn--primary` Apply, `btn--icon` Hide (transparent, VisibilityOff small, intentionally asymmetrical `margin -1.35rem -1.75rem` for larger touch target away from the cam image) and Pin selector (transparent, large gold PushPin 30deg `1.5rem` `var(--color-gold)` → `var(--color-accent-strong)` on hover, symmetric padding, `title` + `span.sr-only` over a native hidden `input type=checkbox` so the entire card can be the visual selector: `webcam-card--pin-unselected` dashed faint vs `webcam-card--pinned` thick solid accent), Jump to top as `webcams__jump` pills. **Icons are Material UI SVG components** (`@mui/icons-material`, added 2026-08-29): Refresh, FilterList, VisibilityOff (hidden sources + Hide), PushPin (pin selector 30deg), FiberManualRecord (auto-refresh live dot), DarkMode (Astro).
- **Hidden storage**: `localStorage["sw:webcams:hidden:v1"] = JSON.stringify(ids: string[])`, versioned; modal lists hidden entries with per-row Show and a "Show all" affordance; a hidden item stays hidden under every region filter. **Filter storage**: `localStorage["sw:webcams:filters:v1"] = { v: 1, regions: [...] }` (added 2026-08-29, ticket 02 - the ticket requires the filter to persist across visits but names no key); both keys fall back to their default (empty) on corrupt or foreign-shaped data. **View storage**: `localStorage["sw:webcams:view:v1"]` (added 2026-08-31) is the selected viewing mode, one of "curated" | "selection" | "all", defaulting to "curated" on corrupt or unknown values.
- **Twitch parent param**: one `parent` value per deploy target (localhost for dev, netlify + gh-pages domains); component builds `https://player.twitch.tv/?channel={channel}&parent={parent}&autoplay=false&muted=true`, iframe `title`, no autoplay.
- **Freshness copy** is fixed shape: "Loaded {HH:MM local} · operator refreshes every {N} min". No fabricated ages (CORS). Seasonal cams add their note ("Operates when dark — currently inactive in summer").
- **Nav & routes**: `/webcams` route; nav entry "Webcams" between Dashboard and Details (`Nav.tsx:142` region); `Nav.test.tsx` extended. Webcams page follows product-page pattern (h1, freshness line, per `coding-standards.md`).
- **No new data colors**: cards use `--color-*` tokens; region tags are text/border chrome only (ADR-0002).
- **Vocabulary** per CONTEXT.md: **Webcam**, **Camera station**, **Webcam link**, **Live cam**, **Live updates** (added 2026-08-29); UI copy avoids bare "live".

## Testing Decisions

- **Config contract test** (`src/data/webcams.test.ts`): every entry has unique id, non-empty name/region/operator; every image entry has imageUrl (https), latitude, alt, cadenceMinutes ≥ 1; license is string or null; regions belong to the closed set; `refreshable` only on image entries; every curated id resolves to a distinct image entry carrying longitude (Porjus #1/#2/#5 updated with 19.83); AuroraMAX ships under short name "Yellowknife" (alt still "AuroraMAX – Yellowknife, Canada – current sky view", original preserved as comment).
- **Sun-position tests** (`src/data/sun.test.ts`, added 2026-08-31): equinox/solstice elevations, polar day/polar night at Tromsø, actual sunrise-sunset windows at a US longitude (before sunrise dark, after sunrise light, twilight counted as dark), western-longitude time shift.
- **View-mode storage tests** (`src/data/webcam-storage.test.ts`, added 2026-08-31): round-trips each mode, defaults to "curated", falls back on corrupt/unknown values.
- **Page component tests** with a small fixture config: image card renders title with latitude + region + "Loaded · refreshes every" + attribution + Visit site; link rows render after image cards; the filter dialog's checkbox checklist narrows both kinds (checked state asserted natively); Show all / Hide all toggle every draft checkbox without touching the hidden set; hide removes the item and writes `sw:webcams:hidden:v1`; Hidden sources dialog lists, counts, and restores; the applied filter persists under `sw:webcams:filters:v1`; auto-refresh checkbox default off persists on; header Refresh busts every image card and updates per-card "Loaded" times (fake timers); refreshable cards reload at exactly `max(cadence, 1)` and never before, non-refreshable/Twitch/link rows never reload (fake timers); hidden-tab pause via mocked `visibilitychange` + fake timers (pause/clear, resume/re-arm, manual Refresh still works); UAF live card tested with a mocked `EventSource` (message → img src resolves the frame path, error → fallback note with operator link and no freshness claim, recovery on next frame, feed closes on consent-off/toggle-off/hidden and reopens, reverts to the placeholder whenever the feed stops). **Viewing-mode tests** (added 2026-08-31, all with a pinned `now` prop): tablist semantics (three tabs, aria-selected, tabindex, panel labelling, arrow-key + Home/End activation, tab persistence across mounts, settings untouched by tab hopping); toolbar gating (Filter/Hidden sources and per-card Hide buttons only in My selection); curated darkness (all dark → full set, mid-summer morning → the Tromsø cam steps aside, all daylight → only the Twitch stream remains, filter/hidden ignored, flat grid with no region sections and no Jump to row); All cameras (hidden + filtered entries all return); offscreen pins (strip lists pinned-but-invisible cams with working Unpin toggles, freeing a slot unlocks visible checkboxes, hidden sources' pins stay reachable).
- **Axe/Playwright** (`e2e/webcams.spec.ts`): route `/webcams` with intercepted image responses; assert h1, chips, one card with latitude title, link rows after cards, toggle `aria-pressed`, modal opens with focus, axe audit green (per `coding-standards.md:36`); existing smoke journeys updated for the new nav item.
- **No snapshots**; assert external behavior per `coding-standards.md:39`.

## Out of Scope

- Own cameras, hosted/proxied imagery, scraping operator sites for metadata (alt-text weather data stays on the operator's page).
- User-submitted webcam links (curated set only; moderation is not a product feature).
- True timestamps/`Last-Modified` reads (blocked by CORS on all verified sources).
- Auto-refresh on by default, or any background refreshing when the tab is hidden (ADR-0003 discipline).
- Video autoplay anywhere (Twitch `autoplay=false` only; YouTube cams are links, not embeds).
- NZ/Tasmania, Siberia, UK, Iceland image cams — no verified embeddable stills exist (link rows only; gaps named in the "Looking for more?" note).
- Anything needing a backend (ADR-0001): Push notifications, server-side polling, stream proxying.
