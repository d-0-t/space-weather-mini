# 0006: Offline PWA with honest stale data and personal oval (OVATION canvas + view distance)

We add a Service Worker at build time and a personal oval on Home that answers *can I see it from my town* without lying. The app is still client-side-only per ADR-0001, still `suncalc` on device per ADR-0005, and still polls live JSON per ADR-0003 — this ADR locks how the offline shell, the map, and the distance band work together.

Why: the app currently does not load without internet (`vite.config.ts:1` has no worker). Chasers on the hill need the shell to open offline and the last forecast to stay visible with honest age. They also need an *honest* local answer: the OVATION `Forecast Time` grid (`services.swpc.noaa.gov/json/ovation_aurora_latest.json:42` ~900 KB, 1° `Observation Time`/`Forecast Time`/`Data Format [Lon,Lat,Aurora]`) gives per-cell forecast energy `0–25` quiet today (46k cells `0` transparent), `≥6` already rare, `≥16` top 2% — not Kp. Kp (`CONTEXT.md:72`) is planetary; `Aurora` is local. A single `240 km` looks like a fact and was `wontfix` in `horizon-1-now-dashboard/issues/03-where-am-i-distance-pill.md:9`; we replace it with a band + confidence.

**Status**: accepted

**Considered Options**:

- No worker / AppCache — rejected, breaks on reload offline.
- `vite-plugin-pwa` `generateSW` with Workbox `StaleWhileRevalidate` for `services.swpc.noaa.gov`, `CacheFirst` for Stadia tiles + OVATION JPGs — picked, static Netlify/gh-pages build stays zero-ops, one `manifest.json:1` `display:standalone` already exists.
- Per-page stale hiding (`Never show stale`) — rejected, chaser would be blind; we keep stale with `As of` + `⚠ Showing saved data`.
- Separate place pickers for Home and `/conditions` — rejected, duplicates `geocoded place` (`CONTEXT.md:167` single `localStorage["sw:local-conditions:place:v1"]`). Reuse one `PlaceFinder` modal next to the short name on both pages, icon-only on narrow with `sr-only`.
- Full pannable world map at zoom 6+ — rejected, burns Stadia tiles (64→256). Locked `minZoom 1` / `maxZoom 2-3` world view (2→4 tiles, horizontal wrap) shows both caps via `North | South` toggle (OVATION has north + south payloads), ~8 tiles total, well within Stadia free.
- Single-number distance (`Aurora 240 km N`) — rejected as misleading — picked band table with confidence, `0` transparent.
- Hatch + contour on default map — rejected for clean default; picked hatch + contour only in color-blind mode. Default stays NOAA-like color wash; color-blind mode swaps palette and adds pattern.

**Consequences**:

- `vite-plugin-pwa` added to `vite.config.ts:1`, `VitePWA({ strategies:'generateSW', registerType:'autoUpdate', workbox:{ globPatterns:['**/*.{js,css,html,woff2}'], runtimeCaching:[{urlPattern:/services\.swpc\.noaa\.gov/, handler:'StaleWhileRevalidate', options:{cacheName:'swpc', expiration:{maxEntries:50, maxAgeSeconds:3600}}}, {urlPattern:/tiles\.stadiamaps\.com/, handler:'CacheFirst', options:{cacheName:'stadia', expiration:{maxEntries:20, maxAgeSeconds:604800}}}, {urlPattern:/services\.swpc\.noaa\.gov\/images\/animations\/ovation/, handler:'CacheFirst', options:{cacheName:'ovation-jpg', expiration:{maxEntries:30, maxAgeSeconds:3600}}}]}, includeAssets:['favicon.ico','assets/*'], manifest:false })` with `skipWaiting` + `clientsClaim` for iOS. Shell precached; first visit must be online; iOS 7-day eviction documented honestly. Offline UI everywhere: `As of {Forecast Time} • Updated {age} • ⚠ Showing saved data — couldn't reach NOAA` when `isError && data` (mirrors `forecasts/3-day-forecast.tsx:106` stale branch), plain error when never loaded.
- One `geocoded place` shared: `Home` `AuroraNow` line `Aurora ~band from [shortName] (i)` + `Update location` button + same modal `PlaceFinder` used on `/conditions` (refactored from section to `location icon+shortName` button). `device location` (`CONTEXT.md:171`) via `getCurrentPosition({enableHighAccuracy:true, timeout:8000, maximumAge:60000})` reverse-geocoded via Nominatim, becomes stored place only on confirm. `±{accuracy}m` shown.
- OVATION canvas: fetch `ovation_aurora_latest.json`, decimate 1° grid, project equirectangular to `<canvas>` over Stadia `alidade_smooth_dark` tiles (locked zoom). `Forecast Time` shown, not `Observation Time`, with 30–90 min lead note. `Aurora 0` transparent. Starting bands `1-5 faint / 6-10 moderate / 11-15 strong / 16+ intense` (calibrated live; `max 25` today, higher in storm) mapped to frozen `.kp01–.kp9` palette reused via `color-mix` (`docs/adr/0002:3` never variable-ized). Default: color wash only. Color-blind mode (`localStorage["sw:oval:cb:v1"]` toggle, `aria-pressed`): same bands remapped to Okabe-Ito/viridis safe ramp + alternating hatch (`\` vs `/` vs `X`, neighbours never share) + thin white contour per band edge. Hatch via `OffscreenCanvas` `CanvasPattern` 16×16 @ 6% opacity. Legend shows swatch + hatch + line style; canvas `role="img"` `aria-label` lists bands; hidden `<table>` is source of truth (`docs/agents/coding-standards.md:26`). Hover/tap tooltip `Aurora 14 ~ Kp 6` optional.
- View distance (`CONTEXT.md` new term): band to nearest cell `Aurora ≥6` within 600 km, haversine ring. Table `Overhead / Nearby ~0-100 km • Likely / Distant ~100-300 km • Possible / Far ~300-600 km • Unlikely` + `Not in range`. `(i)` explainer: `Forecast, not a photo. Each colored square is 30-min forecast (1°). 0 = no forecast. Cloud/moon/town lights can still hide it.` Stored thresholds versioned for migration.
- Light pollution stays link-out per ADR-0005; no Bortle number invented. Webcams aggregation unchanged per ADR-0004.
- Honest copy everywhere: `30-min forecast` provenance `https://www.swpc.noaa.gov/products/aurora-30-minute-forecast` Newell 2009 link in explainer, no promise of background alerts, no periodic background sync (0% iOS `research:185`).
